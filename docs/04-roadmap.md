# ForgeAI Roadmap

ForgeAI is being developed incrementally, with each version introducing a major layer of functionality.

---

# v0.1.0 — Core Backend / MVP Foundation ✅

The initial version focused on establishing the backend foundation of ForgeAI.

### Completed

- User authentication
- JWT authentication
- Authentication middleware
- Organization management
- Organization members
- Project management
- Task management
- MongoDB database models
- Controllers
- Services
- REST API routes
- Authorization and access control
- Backend project structure
